## 6. How to play

1. Tu personaje corre hacia delante él solo.
2. Toca cualquier parte de la pantalla para cambiar de color: Rojo → Azul → Verde → Amarillo → Rojo…
3. Mira la siguiente puerta. "=" significa el MISMO color que la puerta. "≠" significa un color DIFERENTE.
4. Cruza todas las puertas hasta la meta. Con el color equivocado fallas el nivel y pierdes una vida.
5. Atento a las novedades: las puertas de memoria ocultan su color, las zonas espejo invierten el orden y las puertas con palabras intentan engañarte.
